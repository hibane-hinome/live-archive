# 火羽 · 录播字幕（浏览器扩展）

看录播的时候，把直播当时的逐句翻译叠在画面上：日文原文在上（小）、中文翻译在下（大），
逐句跟着视频走。字幕数据来自 LiveTranslate 的翻译数据库，随存档站一起发布在
GitHub Pages 上，插件每天自动取最新。

## 安装（Chrome / Edge，开发者模式）

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）
2. 右上角开「开发者模式」
3. 点「加载已解压的扩展程序」，选这个 `extension/` 文件夹
4. 打开任意一个录播视频页（`www.bilibili.com/video/BV...`）

装好后播放器右下角会出现一个圆形「译」按钮，点开就是控制面板。

## 日常使用

- **看字幕**：装上就生效，自动匹配场次；匹配不上时面板里手动选一场。
- **字幕和画面错开**：面板「对时」一行，`−10 / −1 / +1 / +10` 往前或往后推字幕。
  每个视频调一次就记住了（按稿件存）。
- **显示模式**：双语 / 仅中文 / 仅原文。
- **字号、高度**：两个滑杆，全屏同样生效。

## 场次是怎么对上的

按顺序试，命中即止：

1. 你在面板里手动选过的（按稿件记住）
2. `site/data/videos.json` 里的稿件映射（见下）
3. 稿件标题或简介里的标记：写一句 `HBS:2026-11-11_0904` 就能钉死
4. 按稿件发布时间倒推：取"结束时刻在发布时刻之前"的最近一场（7 天内）

日常其实 1 和 4 就够了：发布时间推断基本准确，不对再手动选。

## 字幕数据是怎么来的

```
LiveTranslate (translation_history.db)
        │  tools/export_subs.py（build.py 构建时自动调用）
        ▼
dist/subs/index.json          场次目录 + 稿件映射
dist/subs/<场次>.json         [[起秒, 止秒, 中文, 日文], ...]
        │  git push → GitHub Actions → Pages
        ▼
https://hibane-hinome.github.io/live-archive/subs/...
        │  插件拉取（index 缓存 3 小时，弹窗里可强制刷新）
        ▼
播放器上的字幕层
```

- 时间轴是「距本场第一句翻译多少秒」，不是距开播整点——录播开头差的那几十秒
  用「对时」补。
- 碎句按停顿合并成块（间隔 <1.6s、总长 <42 字），避免逐词闪烁。
- 字幕轨直接读数据库全量，**比站点多**：站点只收 23:30–01:30 开播的场次，
  白天场这里照样有。

## 每天/每场更新

不需要额外动作。跑一次 `publish.cmd --push`（导出 → 构建 → 提交 → 推送），
字幕数据就跟着站点一起上线了。插件端最多 3 小时后自动拿到，或在弹窗里点「刷新字幕数据」。

## 有新录播投稿时

在 `site/data/videos.json` 里加一行（没有这个文件就新建）：

```json
{
  "BV1xx411c7mD": "2026-11-11_0904"
}
```

或者在投稿简介里写 `HBS:2026-11-11_0904`。两者选一即可，映射表优先级更高。

## 本地预览（改插件时用）

```
python -m http.server 8801 --bind 127.0.0.1     # 在仓库根目录
# 浏览器打开
http://127.0.0.1:8801/extension/test/preview.html
```

预览页模拟 B 站播放器结构，字幕数据走本地 `dist/`。参数：
`?key=场次&t=秒&noraf=1`（跳到指定秒渲染）、`&panel=1`（打开面板）。
`testsrc.mp4` 是带时间码的测试视频，没提交仓库，重新生成：

```
ffmpeg -f lavfi -i "testsrc=duration=120:size=960x540:rate=30" \
       -pix_fmt yuv420p -c:v libx264 extension/test/testsrc.mp4
```

## 文件

| 文件 | 干什么 |
| --- | --- |
| `manifest.json` | MV3 清单；content script 只注入 B 站视频页 |
| `background.js` | 取数据的中转（绕开页面 CORS/CSP），带内存缓存 |
| `content.js` | 主逻辑：场次匹配、字幕渲染、对时、面板 |
| `overlay.css` | 字幕层与面板样式（全部 `hbs-` 前缀） |
| `popup.*` | 扩展图标弹窗：状态检查 + 强制刷新数据 |
| `test/preview.html` | 本地预览页（模拟 B 站结构） |
